Verify it, don't trust it

      

        Open the Network tab and paste a production secret. You will see no
        requests, because there is no server to send them to — the parsing
        happens in JSON.parse and DOMParser, right
        on the page.
      

    

    

      
Works with the tab closed

      

        Each tool is one HTML file with no framework and no analytics. Save the
        page to disk and it keeps working on a plane, behind a firewall, or on
        an air-gapped machine.
      

    

    

      
Built for large files

      

        Trees render in chunks and searches stop at a sane budget, so a 40 MB
        manifest opens instead of freezing the tab.
